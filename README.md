# Карты, игры и проекты

Сайты для занятий и презентаций Артёма Распопова.

## Содержимое

- `public/rap-karta-moskvy/` — общая рэп-карта Москвы.
- `public/moskva-gufa/` — Москва Гуфа.
- `public/karyernaya-karta/` — карьерная карта ФИДиЖ.
- `public/birzha-talantov/` — биржа талантов, демоверсия.
- `public/index.html` — каталог проектов; включает ссылку на отдельно опубликованную игру «Дело издателя».

## Обновление

Изменение файлов в `public/` в ветке `main` автоматически публикует новую версию через GitHub Actions. Для нового проекта добавьте папку с `index.html` и ссылку в каталог.

Рэп-карта использует прежнее веб-приложение Google Apps Script. Данные остаются в прежней Google-таблице. Google Apps Script, Google-таблица и карты OpenStreetMap работают отдельно от GitHub Pages.

Публикация не добавляет серверную логику к демонстрационным формам биржи и карьерной карты: эти формы остаются демоверсиями.


## Учебные игры

- [Ведомости](https://raspopovtema-code.github.io/vedomosti/) — Печатный двор 1702–1727 годов: подготовка и выпуск первых газет.
- [Редакция](https://raspopovtema-code.github.io/redaktsiya/) — Первый рабочий день журналиста: одиннадцать ситуаций, решения и их последствия.
- [Этика. Детектив](https://raspopovtema-code.github.io/etika-detektiv/) — Найдите нарушения этики в журналистских текстах и определите их тип.
- [Фейкостан](https://raspopovtema-code.github.io/feikostan/) — Решения пресс-службы во время скандала и разбор информационной модели.
- [Первый день в редакции «Трэш и Угар»](https://raspopovtema-code.github.io/reportazh/) — Учебная игра о том, как работать над репортажем.
- [Выжить в эфире](https://raspopovtema-code.github.io/vyzhit-v-efire/) — РКН против редакции: десять кейсов для обсуждения и командной игры.

Игры опубликованы из предоставленных HTML-файлов без изменений содержания.
